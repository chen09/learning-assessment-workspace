# Learning Assessment Workspace

An open MVP for family learning with digital worksheets, typed and selected answers, handwritten or photographed work, AI-assisted feedback, and correction cycles.

## Product Direction

- Present a child with a question set.
- Support choice answers, typed text, on-screen handwriting, and photographed paper work.
- Preserve each submission and return per-question feedback for review and correction.

The first release is a responsive web application and installable PWA. The exact AI provider is intentionally undecided.

## Data and Privacy

This is a public source repository. It must never contain student identities, answers, photos, production database exports, API keys, or private service credentials.

Runtime data will be stored separately in managed private services. Supabase is the current candidate for PostgreSQL, authentication, and private file storage.

## Status

The project is in product and technical design. No application code or production integration has been released yet.
